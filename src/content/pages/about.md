I'm Sakina. I make small tools for things that bug me, mostly command-line ones, plus plugins for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) and now and then a Minecraft mod.

A lot of it starts with a site I use all the time that has no API. I open the network tab, look at what the page actually asks its server for, and a few evenings later there's a CLI. [ikea-cli](https://github.com/soffits/ikea-cli) happened that way. I also like checking other people's numbers myself, which is how [ECI Live](https://soffits.github.io/eci-live/) started, and right now I spend a lot of time on [rummage](https://github.com/soffits/rummage), which I use to search my notes and old chats by meaning instead of exact words.

My favourite bugs are the ones that look impossible at first, like a [login link that returned 200 and an error page](/blog/the-login-link-returned-200-and-an-error/). Most of the posts here are about bugs like that. The code is on [GitHub](https://github.com/soffits), and the [projects page](/projects/) lists what I'm working on.
