**Hi, I'm Sakina.** I'm a programmer who likes building fast, practical command-line tools, browser extensions, and Minecraft mods.

Most of my open-source repositories start because I got tired of clicking through a slow web UI or maintaining a brittle one-off script. Lately that has meant [ikea-cli](https://github.com/soffits/ikea-cli), [bookfetch-cli](https://github.com/soffits/bookfetch-cli), [seafile-vault-cli](https://github.com/soffits/seafile-vault-cli), [canvas-student-cli](https://github.com/soffits/canvas-student-cli), [jobloom](https://github.com/soffits/jobloom), and [OpenPlayer](https://github.com/soffits/OpenPlayer).

When a bug takes an unexpected turn (an Auth0 error page returning HTTP 200, a hover button sliding out from under the cursor, or `tailscale0` losing its routing table on OpenWrt), I write up the diagnosis and the fix here so I have it next time (and in case someone else searches the same error line).
